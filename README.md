# Lista de Navidad

App familiar para escribir la carta a los Reyes Magos (o a Santa Claus) y organizar los regalos en el taller de los elfos.

- Web estática (HTML, CSS y JavaScript sin compilación), publicada con GitHub Pages.
- Datos e inicio de sesión con Supabase (código de 6 cifras por correo).
- Vista previa de cada pantalla sin conexión: añade `?demo=sobre`, `?demo=carta`, `?demo=taller`… a la dirección.
